## 📌 Executive Summary

**Afumado** is a multi-page enterprise real estate platform engineered for ultra-high-net-worth (UHNW) private clients, family offices, and institutional investors. Unlike conventional bloated themes, this system was developed from the ground up prioritizing **Core Web Vitals, data integrity, micro-interactions, and frictionless mobile publishing**.

⚡ Key Engineering Highlights
1. 🧮 Client-Side FinTech Calculators (Vanilla JS)
Instant Estate Valuation Engine (/valuation): Calculates property worth in real time using algorithmic multipliers based on metropolitan postal districts, living area (Sq Ft), and architectural standards. Smoothly auto-scrolls to live output and encodes appraisal metrics into a WhatsApp booking link.
Interactive Mortgage Estimator (/property-detail): Live JavaScript amortization model calculating monthly debt obligations based on down-payment percentages and loan tenures at dynamic interest rates.
2. 🏛️ Advanced Data Normalization (ACF Architecture)
Decoupled hardcoded templates into structured database fields:
Living Area, Metric Conversions, Price formatting, Beds/Baths.
Multi-angle client-uploaded interior galleries.
Embedded 4K video walkthrough tour pipelines (YouTube / direct MP4).
3. 💬 WhatsApp Automated Conversion Funnel
Replaced standard generic web forms with automated deep-linked WhatsApp API endpoints (https://wa.me/).
Injects active listing titles, calculated valuations, and canonical URLs into pre-filled chat messages, boosting lead conversion by eliminating manual inquiry friction.
4. 👑 Role-Based Frontend Content Management
Built-in security checking via current_user_can('edit_post'):
Logged-in Admin: Sees a floating ➕ Add Property button on mobile and inline [✏️ Edit] / [🗑️ Delete] controls.
Public Visitors: Experience a sanitized, read-only luxury interface with zero administrative clutter.
5. 🎨 60fps Native Hardware-Accelerated Animations
Ken Burns Slow-Mo Reel: Pure CSS GPU-rendered (transform: scale()) cross-fading architectural reel running at 60fps with zero JavaScript layout thrashing.
Scroll-Reveal Engine: Built using native IntersectionObserver API—elements gracefully glide and fade upward on scroll with zero external library overhead.

🛠️ Technology Stack & Libraries
Core Backend: WordPress, PHP 8.1+, REST API, Custom Action & Filter Hooks (the_content, get_the_excerpt, wp_footer).
Data Layer: Advanced Custom Fields (ACF).
Frontend Design: Tailwind CSS, Modern CSS Grid, Flexbox, Custom Glassmorphism.
Optimization: WebP Image Compression, Native Image Lazy Loading (loading="lazy"), Minified Inline Assets.
SEO & Compliance: Yoast SEO Structured Metadata, OpenGraph Protocol, Semantic Schema HTML5.
